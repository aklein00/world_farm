WORKING PROPOSAL / 01.B / 10 NOVEMBER 2026

One style.
A family of buildings.

Set the visual rules once. Build a collection of editable structures that belong together, then arrange them into a small world.

THE IDEA

A shared style,
not a fixed building.

Keep palette, windows, doors, roofs and trim coordinated without making every building the same.

Input
Style family + building brief
Working set
Shop · townhouse · workshop
Output
Editable project · GLB · PNG

Designed for look development, composition studies and reusable environment kits.

THE JOURNEY

From a style family to a little world.

Based on the current 01.B review workflow. These five stages map to its twelve screens.

  1. 01–02

    Define the family

    Choose a starting style, name the family and save the shared visual rules as a version.

  2. 03–05

    Make and customize

    Describe a building, choose a sample candidate, then edit Building, Windows, Doors and Roof. Pin local changes.

  3. 06–07

    Save a reusable kit

    Keep each building’s structure, style link and overrides together. Repeat for different building types.

  4. 08–09

    Assemble and review

    Place copies on reserved plots, adjust the block and check the camera view. Export the project, sample GLB or PNG.

  5. 10–12

    Revise deliberately

    Preview a shared-style revision, choose which buildings receive it, preserve pinned edits and keep earlier versions.

    Optional revision loop
